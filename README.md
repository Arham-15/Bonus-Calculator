# Bonus Calculator

A Python-based application that calculates employee bonuses based on salary and bonus percentage. The project demonstrates fundamental Python concepts including user input, arithmetic operations, conditional logic, and formatted output.

## Features

* Calculate bonus amount from salary and percentage
* Display total salary after bonus
* Simple and user-friendly interface
* Beginner-friendly Python project

## Technologies Used

* Python 3
* NumPy

## Project Structure

```text
bonus_calculator/
│
├── bonus_calculator.py
├── README.md
└── .gitignore
```

## How to Run

1. Clone the repository:

```bash
git clone https://github.com/Arham-15/Bonus-Calculator.git
```

2. Navigate to the project folder:

```bash
cd Bonus-Calculator
```

3. Run the program:

```bash
python bonus_calculator.py
```

## Example

Input:

```text
Enter Salary: 50000
Enter Bonus Percentage: 10
```

Output:

```text
Bonus Amount: 5000
Total Salary: 55000
```
